# Open-Source Electricity Demand Forecasting Prototype

A Python-based prototype demonstrating short-term electricity demand forecasting using historical time-series data.

## Project Structure
* `data/`: Contains raw and processed time-series data (ignored by git).
* `notebooks/`: Jupyter notebooks for exploratory data analysis (EDA).
* `src/`: Python source code for preprocessing and feature engineering pipelines.
* `models/`: Trained baseline and candidate model artifacts.
